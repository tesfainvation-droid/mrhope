1. This website

This is a static website. It does not use cookies, analytics, tracking pixels or advertising, and it has no forms or user accounts. It does not ask you for any personal information. Contact is by email only.

2. If you email me

If you write to tesfainvation@gmail.com, I receive your email address, your name if you include it, and whatever you choose to write. I use this only to reply to you and, if we work together, to manage that engagement. I do not sell it, share it for marketing or add you to a mailing list. I keep correspondence only for as long as it is needed for those purposes or as required by law.

3. Hosting and fonts

Like any website, loading these pages involves a couple of third-party services that receive technical information from your browser:

  • Hosting. The site is hosted on GitHub Pages. GitHub may log technical data such as your IP address to operate and secure the service. See the GitHub General Privacy Statement.
  • Fonts. Typefaces are loaded from Google Fonts, so your browser connects to Google's servers, which receive your IP address. See the Google Privacy Policy.

I do not receive or control these logs.

4. Tesfa Hermes YouTube app

Tesfa Hermes YouTube is a private tool that publishes videos to, and manages, YouTube channels owned by its operator, Tesfa Melese. It is not offered to the public. It only accesses accounts whose owner signs in with Google and grants permission.

What the app accesses

When the channel owner signs in with Google, the app requests permission to:

  • upload videos;
  • view the channel and its videos;
  • view YouTube Analytics reports;
  • manage comments on the owner's own channels.

How the data is used

This data is used only to publish the owner's videos, measure how they perform, and reply to comments on the owner's channels.

Sharing

The data is not sold, not shared with third parties and not used for advertising.

Tesfa Hermes YouTube's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

Sign-in tokens are stored only on the owner's private server, readable only by the owner's account. No data about viewers is stored beyond the public comment text needed to write a reply.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops all access immediately.
